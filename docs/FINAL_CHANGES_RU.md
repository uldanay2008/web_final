# Изменения для финала — исходный дизайн

Основа: текущий GitHub web_ass5, коммит 178853c. Это исправленная версия именно этого проекта, а не предыдущий вариант с переработанным дизайном.

- Light / Dark: переключатель на каждой странице; выбор сохраняется и применяется до отрисовки страницы. В тёмной теме Change background отключён, чтобы фон не конфликтовал с темой.
- Account: регистрация, проверка повторного email, вход, ошибки, spinner и блокировка повторной отправки.
- Profile: имя, email, телефон, избранное браузера и выход. Гость видит приглашение войти.
- Products: публичный DummyJSON beauty API через fetch/async-await. Пять демо-товаров, загрузка, HTTP-проверка, таймаут, сообщение ошибки, повтор.
- Формы: novalidate, все проверки в JS. Email, обязательные поля, пароль 8+ с заглавной/строчной/цифрой/символом, подтверждение пароля, телефон 7–15 цифр. Телефон обязателен при выборе Phone. Полная и пошаговая форма используют одинаковый модуль.
- Все задачи Assignment 6 сохранены; счётчик страниц обновлён с 6 до 8. Подсветка FAQ не раздвигает слова.
- Для недоступных внешних изображений добавлен локальный fallback.

## Какие файлы заменить

Весь комплект HTML, CSS и JS из архива. Новые файлы: account.html, profile.html, css/final.css, js/theme-init.js, js/validation.js, js/final.js, assets/image-unavailable.svg. Не вставляйте новый JS в конец старых файлов: заменяйте совпадающие файлы. Сохраните .git и историю проекта. Существующий .github/workflows сохранён.

## Где проверять

Home: тема и счётчик 8. Account: пустые поля, слабый пароль, несовпадающее подтверждение, повторный email, корректная регистрация. Profile: данные, избранное, выход. Contact: email, пароль, Phone/номер в полной и пошаговой форме. Products: поиск и избранное прежние; API ниже основного каталога.

## Важное

Авторизация учебная: localStorage и код можно изменить. Хранится salted SHA-256 digest, но это не настоящая защищённая серверная авторизация. Используйте вымышленные данные. Поля Contact остались учебным примером из предыдущих заданий и не создают аккаунт.

GitHub в этой сессии не обновлён из-за отсутствия авторизации для записи. После замены файлов выполните Commit/Push и дождитесь Pages workflow. Частный предпросмотр предназначен владельцу; для преподавателя используйте проверенную публичную GitHub Pages-ссылку.

Предыдущий PDF-отчёт для версии с 9 страницами не соответствует этому варианту с 8 страницами: перед сдачей актуализируйте описание страниц и скриншоты.
